# dl-helper

개인용 유저스크립트 두 개. 비공식이며 DLsite·dlwatcher와 관계없습니다. 이 폴더는 백업을 겸해 자동으로 갱신됩니다.

## 설치
Tampermonkey(또는 Violentmonkey)를 깔고 아래 파일을 열어 설치합니다. 이후 새 버전은 자동으로 받습니다.

- `dlsitehelper.user.js` — DLsite 화면 정리
- `dlwatcher-search.user.js` — dlwatcher 검색·즐겨찾기

## dlsitehelper
- 검색·필터: 한국어·신작순 기본, 형식·언어·가격·할인·태그를 한 창에서
- 카드 정리: 쿠폰·묶음·할인율·마감·품번 딱지, 형식 줄에 모아서
- 장바구니·즐겨찾기: 고르기, 마감순
- 차단·바로가기·내 기본값
- 작품 페이지: 리뷰 먼저(신착순), 번역 허가 표시
- 라이브러리: ♡·내 태그·메모
- 요청 수를 늘리지 않는 것을 원칙으로 합니다.

## dlwatcher-search
- 품번·서클·성우·작가 검색, 가격 그래프, 즐겨찾기, 새소식

## 주의
- 개인 사용 목적이며 보증하지 않습니다. 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.
- 사이트 이용약관을 지키고, 과도한 요청을 보내지 않도록 쓰세요.
